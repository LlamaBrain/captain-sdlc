## Summary

An MCP server stopped while owning a signed operation lease for the UI pointer-prefab Merge Prep. The existing abort operation applied to implementation-run merges and could not safely release this separate Merge Prep lease. Michael directed creation of a narrowly authorized recovery tool and continuation of the same merge operation.

`captain_recover_merge_lease` checks the merge ID, signed revision, lease token, session, source and target bindings, and owner state before releasing only merge-associated leases. It refuses a live or unverifiable owner. Recovery does not change Git refs or readiness evidence.

The build fingerprint issue was resolved by excluding only the exact Addressables content-state, GameAnalytics settings, and TextMesh Pro fallback outputs regenerated by the LOW Unity build. Other ignored inputs remain fingerprinted.
